# FitPlan - Egzersiz GIF ve Görsel Klasörü

Bu klasör, egzersizlerin yerel GIF veya animasyon dosyalarını barındırır.

Egzersiz kartlarında ve inceleme modalında belirtilen dosya isimleri:
- `squat.gif` (Squat)
- `bench-press.gif` (Bench Press)
- `deadlift.gif` (Deadlift)
- `pull-up.gif` (Pull Up / Barfiks)
- `push-up.gif` (Push Up / Şınav)
- `overhead-press.gif` (Overhead Press)
- `dumbbell-row.gif` (Dumbbell Row)
- `barbell-curl.gif` (Barbell Curl)
- `triceps-pushdown.gif` (Triceps Pushdown)
- `plank.gif` (Plank)
- `jump-rope.gif` (Jump Rope)
- `burpees.gif` (Burpees)
- vb.

Not: Eğer klasörde henüz bir `.gif` dosyası bulunmuyorsa, FitPlan yerleşik modern dinamik biyomekanik vektör simülasyonunu çalıştırır ve "Hareket görseli yerel klasörden kontrol ediliyor" bilgilendirmesini gösterir.
